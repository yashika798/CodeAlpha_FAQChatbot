# 🤖 FAQ Chatbot

A professional FAQ Chatbot built using Python, Streamlit and
Machine Learning.

The chatbot uses TF-IDF vectorization and cosine similarity to
understand user questions and return the most relevant FAQ answer.

---

## 🚀 Features

- 🤖 Interactive FAQ chatbot
- 💬 Real-time chat interface
- 🧠 TF-IDF based text matching
- 🔎 Cosine similarity for question matching
- ⚡ Quick FAQ buttons
- 🌓 Professional dark UI
- 🗑️ Clear conversation option
- 📱 Responsive Streamlit interface
- ❌ Fallback response for unknown questions

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity
